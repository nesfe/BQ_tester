# Графики и события в 2.2

Панели, цвета и расположение элементов сохранены. Графики показывают последние 10 секунд по времени измерения; скорость движения больше не зависит от количества точек в окне. Между опросами прокручивается готовый слой canvas, а линии пересчитываются при поступлении данных. Частота чтения батареи и мост TI CMAPI не изменены.

## Отметки на графике тока

- `↑` — флаг появился; `↓` — снялся; `•` — был активен при первом успешном чтении статуса.
- Красный маркер означает появление защиты SafetyStatus, жёлтый — появление флага OperationStatus, зелёный — снятие флагов, серый — исходное состояние.
- `+N` означает дополнительные события в том же опросе. Наведите курсор на маркер: подсказка содержит все события, время, ток и полное 32-битное значение соответствующего регистра.
- Можно выбрать график клавишей Tab и перемещаться между событиями стрелками. Escape закрывает подсказку. На графике ячеек стрелки выбирают измерения.

Это время **наблюдения при опросе**, а не точное аппаратное время срабатывания. Регистры читаются последовательно. Краткий импульс между опросами может остаться незамеченным. Названия флагов берутся из существующей карты BQ40Z50-R1; неизвестные биты других ревизий не получают выдуманных названий. Исходные значения статусов сохраняются в CSV.

## Пауза и запись

`Pause` замораживает графики. Чтение батареи, текущие карточки, журнал событий и включённая CSV-запись продолжают работать. Измерения во время паузы не добавляются в историю графика. `Resume` возвращает отображение к новым измерениям; пропуски более секунды не соединяются линией. `Clear` очищает историю графиков, сохраняя запись и журнал событий. Новое подключение очищает историю графиков и событий, но накопленная CSV-запись сохраняется.

Неуспешное чтение поля остаётся пропуском, а не нулём. Неизвестный статус не считается снятием защиты. Активные флаги при подключении помечаются как исходное состояние, а не новое срабатывание.

История графиков ограничена 2000 точками, журнал — 1000 событиями (на панели видны последние 50). CSV-запись хранит все валидные измерения в памяти до закрытия приложения; при длительной записи память продолжает расти. Добавление записи больше не копирует весь накопленный массив. Экспорт создаёт Blob блоками вместо большой data URI; добавлены столбцы `SafetyStatus`, `OperationStatus`, `Triggers`.

## Проверка

В `electron_app`: `npm test`, `python -m unittest discover -s bridge -p "test_*.py" -v`, `npm run build`.

Браузерный сценарий использует синтетическую телеметрию через подменённый Electron IPC, без батареи. Проверяет пакет из 101 измерения, паузу с продолжающейся записью, одновременные ON/OFF события, клавиатуру и исчезновение перекрестия, CSV из 102 строк, пропуски, Clear/Resume и повторное подключение.

Пример запуска из корня репозитория с установленным Playwright CLI и работающим Vite на 5184:

```sh
npx --package @playwright/cli playwright-cli open http://127.0.0.1:5184
npx --package @playwright/cli playwright-cli run-code "$(cat electron_app/test/browser/telemetry.playwright.js)"
```

Для сравнения производительности соберите `v2.1.0` в отдельном checkout и текущую ветку (`npm run build` в каждой), запустите их через `vite preview` на портах 5186 и 5187 соответственно, затем выполните `test/browser/benchmark.playwright.js` аналогично. Скрипт подаёт 10 измерений/с, включает CSV, заполняет окно и измеряет 10 секунд при CPU throttling ×4.

Контрольный запуск Chromium в Linux-контейнере, viewport 1550×980, production bundles:

| Метрика за 10 секунд | 2.1.0 | 2.2.0 |
| --- | ---: | ---: |
| Вызовы requestAnimationFrame | 114 | 215 |

Это один синтетический сравнительный запуск, не гарантия FPS на Windows. Новую отрисовку следует проверить с реальным EV2400: включить запись, наблюдать существующие переходы статусов, поставить график на паузу и сверить отметки с CSV. Аппаратный тракт ранее подтверждён пользователем в 2.1.0; изменения 2.2 не добавляют команды записи в батарею.

## Исправление масштаба малых токов

Ось тока автоматически подбирается по фактическому диапазону видимого сигнала, без принудительного включения нуля и без прежнего минимального отступа 0,05 А. Например, для −4…−3 мА получается диапазон примерно −0,0041…−0,0029 А. Число знаков в подписях зависит от масштаба; подписи малых значений не превращаются в одинаковые нули. Для постоянного сигнала предусмотрен небольшой ненулевой диапазон.
