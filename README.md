# BQ_tester — BQ40Z50-R5 Real-Time Telemetry & Status Debugger

> **Windows + EV2400 (Electron 2.1):** используется официальный TI CMAPI через отдельный x86-мост. Требуется установка bqStudio / bqTools SDK с `CMAPI.dll` и `commmgr.exe`. [Инструкция по запуску, сборке и диагностике](docs/EV2400_WINDOWS.md). Описанная ниже архитектура MSP430/WebSerial — отдельный вариант проекта.

**BQ_tester** — это специализированная прослойка (middleware) и инструмент для отладки аккумуляторных батарей (АКБ) на базе микросхемы **Texas Instruments BQ40Z50-R5** с использованием микроконтроллера **MSP430** в качестве моста SMBus/I2C-UART.

---

## 🚀 Зачем нужен этот проект?

Стандартный софт **TI Battery Management Studio (bmsStudio)** отлично подходит для первичной настройки регистров, но **не позволяет строить гибкие графики в реальном времени**. Это делает невозможным отслеживание динамических процессов в АКБ:
- Токовых бросков и просадок напряжения под нагрузкой.
- Дисбаланса ячеек и динамики срабатывания встроенного балансира.
- Точных моментов времени (с точностью до миллисекунд), когда сработали конкретные защиты (**SafetyStatus**: OVP, UVP, OCD, OCC, OTD, OTC, Short Circuit) или изменились флаги транзисторов (**OperationStatus**: DSG, CHG, CB).

**BQ_tester решает эту проблему полностью!**

## ✨ Основные Возможности

1. **Динамические Графики Высокого Разрешения (10 Гц / 100 мс)**:
   - График потребления/заряда тока (Pack Current в А/мА) с нулевой опорной линией.
   - Осциллограмма напряжений каждой из 4-х ячеек (**Cell 1, Cell 2, Cell 3, Cell 4**) в мВ.
   - График общего напряжения АКБ, температуры (°C) и State of Charge (SoC %).
2. **Временная Шкала Статусов и Защит (Status Trigger Timeline)**:
   - Автоматическая фиксация и логирование точных таймштампов срабатывания/снятия любого аларма.
   - Подсветка флагов безопасности (`CUV`, `COV`, `OCC`, `OCD`, `AOLD`, `ASCC`, `ASCD`, `OTC`, `OTD`).
   - Отслеживание состояния ключей заряда/разряда (`DSG`, `CHG`) и балансировки (`CB`).
3. **Совместимость с MSP430**:
   - Готовая C-прошивка для микроконтроллеров MSP430 (MSP430F5529 / MSP430G2553 / MSP430FR5969).
   - Аппаратная поддержка SMBus 1.1 (100 кГц) с подсчетом CRC-8 PEC.
4. **Прямое Подключение из Браузера (WebSerial API)**:
   - Веб-интерфейс подключается напрямую к USB-UART порту MSP430 без необходимости установки дополнительных драйверов или тяжелого ПО.
5. **Встроенный Режим Симулятора АКБ**:
   - Позволяет тестировать графики, эмулировать нагрузку, заряд, просадку ячеек и генерировать сбои прямо в браузере даже без физического подключения платы!
6. **Запись и Экспорт Данных**:
   - Сохранение полных логов испытаний в **CSV** и **JSON** для последующего анализа.

```
 │  └───────────────────────┘ └───────────────────────┘ └─────────────────────────┘  │
 └──────────────────────────────────────────────────────────────────────────────────┘
```

## 🔌 Схема Подключения (MSP430 ↔ BQ40Z50-R5)

| Сигнал MSP430 | Пин MSP430F5529 | Сигнал BQ40Z50-R5 | Примечание |
| :--- | :--- | :--- | :--- |
| **I2C SCL** | P3.1 | SMBC (Clock) | Подтяжка 10 кОм к 3.3V |
| **I2C SDA** | P3.0 | SMBD (Data) | Подтяжка 10 кОм к 3.3V |
| **GND** | GND | VSS / GND | Общая земля |
| **UART TX** | P3.3 | PC RX / USB-UART | Передача данных 115200 8N1 |
| **UART RX** | P3.4 | PC TX / USB-UART | Прием команд |

## 📦 Быстрый Запуск

### 1. Веб-Приложение (Web App)

```bash
cd web_app
npm install
npm run dev
```
Откройте адрес `http://localhost:5173` в браузере Chrome, Edge или Brave.
Выберите режим **MSP430 WebSerial** и нажмите **Connect MSP430 Port**.

### 2. Python CLI Логгер (для консольной отладки)

```bash
cd python_bridge
pip install -r requirements.txt
python bq_tester_cli.py --port /dev/ttyACM0
```

### 3. Прошивка MSP430

1. Откройте **TI Code Composer Studio (CCS)**.
2. Импортируйте проект из папки `firmware/`.
3. Скомпилируйте и прошейте микроконтроллер MSP430.
